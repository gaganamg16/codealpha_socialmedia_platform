\## Tasks



\### CodeAlpha\_Social\_Media\_Platform



A mini social media platform developed using Django.



\#### Features



\- User registration and login

\- User profiles

\- Profile pictures and bio

\- Create and edit posts

\- Upload post images

\- Like and unlike posts

\- Comments

\- Follow and unfollow users

\- Search users

\- Notifications

\- Inbox and messaging

\- Responsive design for mobile devices



\#### Technologies Used



\- Python

\- Django

\- HTML

\- CSS

\- JavaScript

\- SQLite

\- Git \& GitHub
